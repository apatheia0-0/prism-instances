# Cheatbreaker 
Cracked Cheatbreaker client for external launcher by https://github.com/Rushware-Network/CheatBreaker1.8.9/releases/tag/2026/10/8

## Why use this
 Usually The above repos works fine for other launchers like ( Tlauncher, TLegacy, Sklauncher),
 but `Prism Launcher` works in a different way ( instance based ) so its not easy to import the CB cracked to prism launcher
 It took some time for me to figure out on how to do this and really which `.jar` files prism needed to run this CB and then 
 I had to edit the minecraft file to let it use those files.
 
## Installation
 ### Step 1: Download
   - Download or clone the latest release `Cheatbreaker.zip` file.

 ### Step 2: Import
   - Open Prism and click on `Add Instance`
   - Select `Import` then click on `Browse` and select the downloaded `.zip` file.
   - Prism will automatically import all the things and settings.
 
 ### Step 3: Change Java
   - After Successfull import right click on instance and go to `Edit`
   - Go to settings
   - Check the Java installation option
   - Download java ( either `default` or `eclipse_temurin_jre8.0.492+9`)
