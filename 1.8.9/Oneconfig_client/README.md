# Oneconfig 
 Check about oneconfig from here - https://www.polyfrost.org/projects/oneconfig/

## Why use this
 Well there is no particular reason to use this, but if you don't want to download best mods for minecraft pvp
 then you can use this and the best part is you can add your own mods in this.
 This is a `Forge` instance.

## Installation
 ### Step 1: Download
	- Download or clone the latest release `Oneconfig.zip` file from [Releases]
	()

 ### Step 2: Import
	- Open Prism and click on `Add Instance`
	- Select `Import` then click on `Browse` and select the downloaded `.zip` file.
	- Prism will automatically import all the things and settings.
 
 ### Step 3: Change Java
	- After Successfull import right click on instance and go to `Edit`
	- Go to settings
	- Check the Java installation option
	- Download java ( either `default` or `eclipse_temurin_jre8.0.492+9`)
